# 👁 Тренажер зрения по методу Бейтса

Личный ежедневный тренажер (близорукость + астигматизм) по книге У. Бейтса
«Улучшение зрения без очков» и М. Корбетт «Как приобрести хорошее зрение без очков».
Два занятия в день (утро ~8 мин, вечер ~7 мин), таймеры, таблица RNE, карточка
мелкого шрифта, дневник прогресса. Всё хранится в браузере (localStorage), серверов не нужно.

⚠️ Метод Бейтса не признан доказательной медициной. Тренажер — дополнение к наблюдению
у офтальмолога. Соляризация — только с закрытыми глазами.

## Как устроено

- `index.html` — весь тренажер одним файлом. Работает локально и на GitHub Pages,
  с телефона и компьютера.
- `.github/workflows/reminder.yml` — бесплатные напоминания в Telegram два раза в день
  через GitHub Actions.
- `kniga/` — выжимки из книги (не публикуются, в `.gitignore`).

## Программа

- **Дни 1–7** — базовая неделя: только 4 упражнения расслабления (соляризация, пальминг,
  повороты, мысленное представление) — как велит Корбетт, гл. 1.
- **С 8-го дня** — утренний комплекс (Корбетт, гл. 2) + вечерняя работа с таблицей,
  упражнения чередуются по дням: таблица RNE → «меткий стрелок» → «челнок» →
  перемещение по Бейтсу → центральная фиксация → мелкий шрифт.
- Дата начала меняется во вкладке «Памятка».

## Публикация на GitHub Pages (один раз)

1. Создайте на github.com новый **публичный** репозиторий `vision-trainer` (пустой, без README).
2. Отправьте код:
   ```
   git remote add origin https://github.com/hannawebb86/vision-trainer.git
   git push -u origin master
   ```
3. На GitHub: Settings → Pages → Source: «Deploy from a branch», Branch: `master`, папка `/ (root)` → Save.
4. Через минуту тренажер будет доступен по адресу `https://hannawebb86.github.io/vision-trainer/`.
   Откройте его на телефоне и добавьте на главный экран.

## Напоминания

Напоминания приходят из **Google Calendar**: три ежедневных повторяющихся события
(6:30, 13:00, 20:30 по Лос-Анджелесу) с уведомлением и ссылкой на тренажер. Менять время —
прямо в календаре.

Раньше напоминания слал workflow `.github/workflows/reminder.yml` в Telegram, но бесплатный
планировщик GitHub запускал его лишь ~4 раза в сутки в случайное время, и в окна отправки он
не попадал. Workflow отключён (код и секреты Telegram сохранены). Включить обратно:
`gh workflow enable reminder.yml`. Если понадобится Telegram, надёжный бесплатный вариант —
Cloudflare Workers с Cron Triggers.
